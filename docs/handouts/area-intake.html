Intake: getting households into the drive

Intake covers everything from a household registering until each of its children has a card ready for a sponsor. It all lives under Intake in the menu. New to the app? Read the volunteer guide first.

The five Intake pages

PageWhat it's for
RegistrationsForms households sent in, grouped by status (below). The Registration links panel at the bottom holds each school's links; admins manage those.
On holdChildren paused while staff check for a double registration. A child on hold is left out of sponsor matching, printing, and every count. Only an admin can release one.
HouseholdsEveryone in the drive, one row per child. Filter by school or status, search by name or card number, and click a household tag to open and edit it.

What a registration's status means

StatusMeaning and what to do
Waiting on counselorThe household sent the form; the school hasn't confirmed it. It can't be imported yet. If one sits for a long time, mention it to an admin.
Ready to importThe counselor confirmed it. Listed under "Confirmed by counselor, ready to import". An admin imports it.
ImportedIt's now a household in the drive. Nothing to do.
Rejected DuplicateThe counselor didn't approve it, or said it was sent twice. It can't be imported.

Reading a household tag

A tag is the school's code plus a number counted within that school: OL1, OL2, and so on. Households with no school use Z. Each child's card adds their number: OL1.2 is the second child in household OL1. Confidential households are numbered separately, so now and then two households share a tag. If a tag looks doubled, check the school or ask an admin.

Common tasks

Add a household by hand

  1. Check it isn't already in.

    Intake → Households, search a child's first name. If you find them, edit that household instead.

  2. Pick where the referral came from.

    Intake → Add a household. Under Referral source, pick the school if a school counselor referred them, otherwise "Direct referral (no school)". Pick "Confidential" only when an admin or the counselor says the household needs extra privacy. Volunteers without confidential approval won't see it, though you'll still see the ones you enter.

  3. Enter each child.

    First name is required. Add grade, age, sex, sizes, wish list, and specific needs. Type grades as numbers ("10", not "10th") so high schoolers are picked up. High schoolers don't get a wish list; anything typed there isn't saved. Use + Add another child for siblings.

  4. Check the wish lists, then save.

    Once saved, only an admin can change a wish list. Click Save household. The household number is assigned for you. If Save won't go, look for an empty child box and click Remove on it.

This form has no parent name or phone fields. If staff will need them, put them in "Internal notes", which only staff can see.

Fix a typo or add a child

Intake → Households, search the child's name or card number, and click the household tag. Make the change and click Save changes. You can add a wish list to a child who has none. Any change to a wish list that's already saved, even adding one more item, needs an admin. You can't delete a household or a saved child; ask an admin.

A child may be registered twice

You may see "Possibly the same household (same guardian phone)". A household with children at two schools registers once per school and comes in as two households on purpose, so that alone is fine. If the same child appears twice, tell an admin, who can put one on hold.

Run the high-schooler shop day list

Intake → High schoolers. Use the Shop day dropdown on each row, or switch to Board (one column per status) and click Mark invited, Mark confirmed, Mark attended. The Notes box saves when you click away. Copy roster (CSV) copies the list with guardian phone numbers for spreadsheet use. Paste it only where your lead tells you to, and delete it after shop day.

Two people, one household: if someone else saves the same household while you're editing, you'll see "Someone else changed this household while you were editing". Nothing you typed is lost. Choose Reload the latest version unless you're sure yours is right.

For admins

Import a confirmed registration Admin

  1. Open it.

    Dashboard tile Ready to import, or Intake → Registrations. Click a row under "Confirmed by counselor, ready to import". Check that row and the registration page for a "Possibly the same household" note.

  2. Read before you import.

    Check the yellow Counselor corrections box. The counselor's fixes are applied when you import.

  3. Decide on confidential now.

    Click Import this household. If it needs extra privacy, tick "Create this as a confidential household". It can't be switched in the app afterward.

  4. Import and check.

    Click Import now. You'll see a message like "Created Household 3 with 2 children." Click Open the household to see its full tag and look it over. Clicking twice won't make a second copy.

Hold and release Admin

Open the household and click Put this child on hold under the child, give a short reason, and click Put on hold. If a sponsor already has that card, cancel it on Gifts → Fulfillment first. Once it's sorted out, click Release hold on Intake → On hold.
